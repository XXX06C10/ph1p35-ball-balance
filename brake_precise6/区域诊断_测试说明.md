# region_probe：先测机构，再做区域保持

这是独立的**实机采集版**，不执行连续回中。它用于查清 easy3 中心附近反复换向的原因，不代表已经解决抖动。不要把它与 easy3 的回中面板混用。

## 文件与启动

- 烧录文件：`output/region_probe.bit`（与 `output/vision_follow_20261022_region_probe.bit` 内容一致）。
- 配套中文向导：双击 `host/start_region_probe.cmd`，115200、8N1。
- 新源码、旧协议和原电机保护均有核对，完整结果见 `region_probe_verification.json`；完整 SHA256 见 `output/region_probe_sha256.txt` 和 `region_probe_delivery_manifest.json`。
- 连接串口不会发送运动指令。点“准备”只提交 C01 配置；**板上 K2 才开始**，再按 K2 中止。
- K4 立即停止并释放使能；中止后不会自动回中立或续跑。

## 一轮约一分钟

先加载本版 bit，打开本版向导并连接串口。保持同一次串口连接做完三个步骤，日志会自动保存在 `host/logs`。一轮日志应恰好包含三个步骤各一次完成。

1. **静态观察**：固定球但不遮挡识别区，电机可以不使能。点①“准备静态观察”，看到“等待K2”后按板上 K2，观察10秒。该步不发脉冲。等待显示“完成”。
2. **中立观察**：把杆调平，按 K1 锁住电机。把球放到想要的中心，按 K3 记录中心与电机中立位。点②“准备中立观察”，松手后按 K2，观察10秒。该步不发脉冲。若球自行快速滚走导致中止，记录本身就说明当前中立或识别需要先处理。
3. **小幅往返**：先让球静止在中心附近，确认杆仍在刚才记录的中立位。点③“准备±8计数往返”，看到“等待K2”后按 K2。全程不扶球、不碰杆。固件依次执行 `+8→中立→−8→中立`、`−8→中立→+8→中立`、`+8→中立→−8→中立`，共12条腿。每腿到位后，倾斜保持400ms，中立保持600ms。
4. 等待显示“完成”，点④分析本次日志。结果保存在同名 `.probe.json`；点“复制日志路径”即可把路径提供回来。

±8 是相对 K3 中立的**编码器计数**，约为0.7°电机轴角，不等于杆角。每腿使用原慢速定点路径，要求误差≤2计数、持续稳定100ms；单腿发起到稳定超过1秒即中止。不会为了测量而提高频率或角度。

如果中止或重新加载过板卡，请先保留该日志，再断开并重新连接，建立新的日志，从①重新做。先人工恢复调平/放球/K3；不要依赖中止后自动回平。若出现 F1～F8，先排查原因，参数提交或 K1 不会清故障。

## 会中止的条件

- K2、K1关闭、K4、参数/相机配置改变、故障或事件FIFO溢出。
- 非静态观察时，真实识别无效或结果过期；本测量版不使用连续控制的500ms历史目标续行。
- 球距ROI任一边缘≤24个HDMI像素、距K3中心超过120像素，或相邻有效帧速度超过150像素/秒。
- 目标超出绝对±60、中立±8无法容纳在绝对范围内、原P/MC±64、64脉冲/5秒等保护仍有效。
- 到位后的保持期间，电机反馈再次离开±2计数带。

探测失败保持当前使能；K4明确释放。静态观察允许关闭电机，始终不发步。相机ROI仍以1280×720传感器坐标配置，保护会换算到1920×1080球坐标。

## 怎么看结果

分析报告分成四部分：

| 结果 | 内容 | 可以判断什么 |
|---|---|---|
| `static_noise` | 坐标标准差、峰峰值、编码器峰峰值、有效率和帧覆盖率 | 静止球的坐标抖动是否已接近拟采用的15像素保持区，编码器是否自行跳变 |
| `neutral_drift` | 10秒漂移斜率、有效率 | K3中立位是否真的让杆/球接近静止 |
| `motor_response` | 实际STEP数、首个编码器边沿延迟、每腿净反馈/脉冲比例 | 驱动/反馈等待是否合理，换向延迟与重复性是否异常；不会把1计数量化误差直接称为机械回差 |
| `ball_response` | 连续位置模型、三对独立方向增益、留一对交叉验证R² | 杆到球的响应是否足够可辨识、是否能据此选择区域控制参数 |

有效识别率须≥95%，丢失的帧观测保守地不算有效；事件无丢失、无溢出、无故障或中止；三个步骤均完成一次；12条腿齐全；编码器边沿匹配率≥95%；三对球响应方向一致、增益重复范围0.5～2倍；留一对交叉验证R²≥0.70。条件不满足就返回 `INVALID` 并列出原因，不生成参数。

合格结果是 `MEASUREMENT_QUALIFIED_PENDING_REGION_DESIGN`。本版**不会自动生成或应用控制增益**。下一轮才根据数据确定远处回中、预判减速及中立修正参数，再实现“进入±15且低速后保持，离开±25或有明确运动趋势再纠偏”。

## F4记录与协议

VIS=5仍为429字节，D1仍为94字节，P/V/S/C01报文和XOR均未改变；本版只调整D1采样机会为25ms，并添加独立E1事件，原有面板和解析器文件保留。

E1共58字节（含CRLF）：`E1` + 26字节负载的HEX + XOR8的HEX + CRLF，负载大端序：序号16、毫秒时间32、事件位8、P32、MC32、核心状态8、待确认脉冲8、有符号净指令16、有符号反馈增量16、诊断标志8、腿号8、采集状态8、配置选择8、原因8。序号对每次捕获尝试递增；128项FIFO满时锁存溢出并中止测量，不覆盖旧记录。

事件位：0=STEP上升，1=P变化，2=核心状态变化，3=采集阶段/状态/原因变化，4=待确认/诊断变化，5=100ms心跳，6=配置提交，7=DIR变化。同周期多个事件合并一条。诊断标志：7=溢出，6=连续控制检查点静默中，5=段净比例符合原检查，4=存在反方向反馈窗口，3..0=锁存故障。慢速路径的待确认计数表示尚在脉冲/反馈阶段的一次脉冲；快速路径诊断口保留原累计窗口值。

这次运动使用慢速路径，因此**不会主动重现easy3的200Hz检查点F4**。新数据能测出STEP到编码器等待和换向响应，为继续定位提供依据；F4根因仍未实板确认，不能把慢速测试通过写成F4已修复。不延长原5秒超时，不清空未确认反馈来伪装成功。
